# mcgui / mxgui

A graphical front-end (editor, compile/run, visualize) — no real
command-line switches beyond an optional instrument file.

| `mcgui` / `mxgui` | |
|---|---|
| `INSTR` | *(optional)* name of an instrument file to open on startup |
