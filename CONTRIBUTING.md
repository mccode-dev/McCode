# Contributing to McStas / McXtrace

Contributions are very welcome: questions, bug reports, documentation fixes,
components, instruments and code. See [SUPPORT.md](SUPPORT.md) for where to ask
questions and report bugs. Before starting on a larger change, please open an
issue first, so we can agree on the approach.

## Pull requests

- Base pull requests on `main`.
- Keep each pull request to one topic.
- Fill in the relevant parts of the [PR template](docs/pull_request_template.md),
  including the checklist and the AI-tools declaration.

## AI-assisted contributions

Contributions made with AI tools are welcome. A person is responsible for each
contribution, and must understand and have tested it. Commits made with AI
tools, also those from agent accounts, must name the tool in a
`Co-Authored-By` line, for example:

```
Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>
```

AI agents working in this repository should also read [AGENTS.md](AGENTS.md).
