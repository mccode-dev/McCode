# Getting help

- **Questions and discussion:** use the user mailing lists,
  <mcstas-users@mcstas.org> and <mcxtrace-users@mcxtrace.org>. See also
  <https://www.mcstas.org> and <https://www.mcxtrace.org>.
- **Bugs and feature requests:** [open an issue](https://github.com/mccode-dev/McCode/issues/new/choose)
  using the bug report or feature request template. Please include your OS,
  flavour (McStas / McXtrace) and version.
- **Security problems:** do **not** open a public issue. Follow [SECURITY.md](SECURITY.md).
- **Contributing:** pull requests against `main` are welcome. Please fill in the
  relevant parts of the [PR template](docs/pull_request_template.md), which
  includes the checklist and the AI-tools declaration.

Support covers the current 3.x release, with limited support for older 3.x
releases. McStas 1.x and 2.x, and McXtrace 1.x, are deprecated.
