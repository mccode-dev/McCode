# The `Test_KDSource` Instrument

*McStas: Simple test instrument for KDSource*

## Identification

- **Site:** Tests_MCPL_etc
- **Author:** Peter Willendrup
- **Origin:** ESS
- **Date:** April 2026

## Description

```text
Simple test instrument for KDSource, derived from the original KDS_resampled
that was shipped / generated by Jupyter notebook Test_McStas_MPI.ipynb.

Uses an KDSource XML description of bandwidths to apply when resampling the
base MCPL input from samples.mcpl.gz
```

## Examples

- **Test: nloop=1 Detector: PSDMon2_I=4056**
- **Test: nloop=10 Detector: PSDMon2_I=4056**
- **Test: nloop=100 Detector: PSDMon2_I=4056**
- **Test: nloop=1000 Detector: PSDMon2_I=4056**

## Input parameters

Parameters in **boldface** are required; the others are optional.

| Name | Unit | Description | Default |
|------|------|-------------|---------|
| nloop | 1 | Number of reusages of KDSource input | 1 |
