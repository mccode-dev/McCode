# The `PSI_ICON` Instrument

*McStas: McStas model of the ICON imaging instrument at PSI, CH, open beam (no sample).*

## Identification

- **Site:** PSI
- **Author:** Peter Willendrup (DTU/ESS), Estrid B. Naver (DTU), based on earlier model from Ludovic Giller.
- **Origin:** DTU/ESS
- **Date:** June, 2021

## Description

```text
McStas model of the ICON imaging instrument at PSI, CH, without sample: the
camera records the open beam. Based on earlier model from Ludovic Giller.
Assembled from PSI_ICON_beamline and PSI_ICON_camera, as are PSI_ICON_foils,
PSI_ICON_porous and PSI_ICON_porous_Union with a sample in between.
Parameters: see PSI_ICON_beamline.
```
