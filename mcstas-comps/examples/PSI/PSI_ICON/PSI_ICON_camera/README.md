# The `PSI_ICON_camera` Instrument

*McStas: Camera of the ICON imaging instrument at PSI, CH.*

## Identification

- **Site:** PSI
- **Author:** Peter Willendrup (DTU/ESS), Estrid B. Naver (DTU)
- **Origin:** DTU/ESS
- **Date:** June, 2021

## Description

```text
Building block, %include'd after the sample by PSI_ICON and its variants,
see PSI_ICON_beamline. The REMOVABLE Arm stands in for Blende_entrance of
PSI_ICON_beamline so that this file is also a valid instrument on its own.
```
