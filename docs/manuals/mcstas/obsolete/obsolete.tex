\chapter{Obsolete components}
\label{c:obsolete}
\index{Library!Components!obsolete}
\index{Obsolete|textbf}

Components in this chapter have been superseded, typically by a more
general or more robust replacement, and are kept solely so that existing
instrument files referencing them continue to compile and run. \textbf{Do
not use these in new instrument development.} Where a direct replacement
exists it is noted below; run \verb+mcdoc+ on the component name for the
authoritative, current pointer.

\begin{itemize}
\item \texttt{V\_sample} -- superseded by the more general
  \texttt{Incoherent} sample component (see the Samples chapter).
\item \texttt{Virtual\_input}, \texttt{Virtual\_output},
  \texttt{Virtual\_mcnp\_input}, \texttt{Virtual\_mcnp\_output},
  \texttt{Virtual\_mcnp\_ss\_input}, \texttt{Virtual\_mcnp\_ss\_output},
  \texttt{Virtual\_mcnp\_ss\_Guide}, \texttt{Virtual\_tripoli4\_input},
  \texttt{Virtual\_tripoli4\_output}, \texttt{Vitess\_input},
  \texttt{Vitess\_output} -- code-specific neutron event file readers/writers,
  superseded by \texttt{MCPL\_input}/\texttt{MCPL\_output} (see the Misc
  chapter), which use the portable, multi-code MCPL event format instead of
  a McStas/MCNP/Tripoli4/Vitess-specific one. See the User Manual, section
  on choosing an output data file format.
\item \texttt{ESS\_moderator\_short} -- an early, simplified ESS moderator
  model, superseded by \texttt{ESS\_butterfly} (see the Sources chapter).
\item \texttt{Beam\_spy} -- a diagnostic/debugging component superseded by
  more general monitor components (e.g. \texttt{Monitor\_nD}).
\end{itemize}
