\section{The \texttt{Adapt\_check} McStas Component}
Optimization specifier for the Source\_adapt component.

\subsection*{Identification}
\begin{itemize}
  \item \textbf{Author:} Kristian Nielsen
  \item \textbf{Origin:} Risoe
  \item \textbf{Date:} 1999
\end{itemize}

\subsection*{Description}
This components works together with the Source\_adapt component, and is used to define the criteria for selecting which neutrons are considered "good" in the adaptive algorithm. The name of the associated Source\_adapt component in the instrument definition is given as parameter. The component is special in that its position does not matter; all neutrons that have not been absorbed prior to the component are considered "good".

Example: Adapt\_check(source\_comp="MySource")
