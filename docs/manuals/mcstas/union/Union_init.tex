\subsection*{Description}
Part of the Union components, a set of components that work together and thus sperates geometry and physics within McStas.

This component used to be required as the FIRST Union component. It defined the shared library (union-lib.c) and owned the shared global lists, which the other Union components reached via COMP\_GETPAR3.

That is no longer needed: every Union component loads the Union library (union-lib) itself, and the library owns the shared lists. The Union\_init and Union\_stop components are therefore optional.

This definition is kept only so that existing instruments that still place a Union\_init component continue to compile. It emits a deprecation warning and has no effect.
