\section{The \texttt{SANSLiposomes} McStas Component}
A sample of polydisperse liposomes in solution (water).

\subsection*{Identification}
\begin{itemize}
  \item \textbf{Author:} Martin Cramer Pedersen (mcpe@nbi.dk)
  \item \textbf{Origin:} KU-Science
  \item \textbf{Date:} October 17, 2012
\end{itemize}

\subsection*{Description}
A component simulating the scattering from a box-shaped, thin solution (water) of liposomes described by a pentuple-shell model.

\subsection*{Input parameters}
Parameters in \textbf{boldface} are required; the others are optional.
