\chapter{SasView/sasmodels form factors: small-angle scattering}
\label{c:sasmodels}
\index{Library!Components!sasmodels}
\index{SasView|textbf}

This chapter documents the \texttt{sasmodels} category: a large set of
small-angle scattering (SANS/USANS) form-factor models, generated
automatically from the open-source SasView/sasmodels project
(\url{https://github.com/SasView/sasmodels}) and exposed to \MCS as
individual \texttt{SasView\_*} components (each wrapping one sasmodels
kernel via the generic \texttt{SasView\_model} interface). This gives
access to the same, actively maintained library of scattering-law
implementations used for SANS data fitting in SasView itself, directly as
McStas sample components, without needing to hand-implement each form
factor.

Most models exist in a plain (orientation-averaged, i.e. powder/isotropic)
form and, where the shape has a well-defined orientation, an
\texttt{\_aniso} variant that additionally accepts orientation parameters.
For the underlying physics of any individual model (defining equation,
parameter meaning, validity range), consult the corresponding page in the
SasView documentation (\url{https://www.sasview.org/docs/}); the parameter
tables below are generated directly from each component's McDoc header and
give the \MCS-specific parameter names, units and defaults.

See also \texttt{Templates/templateSasView} and
\texttt{Templates/Test\_SasView\_guinier} in the example instrument library
for worked examples, and the \texttt{samples/SANS\_*} and
\texttt{contrib/SANS*} components (documented in the Samples chapter) for
McStas's own, native (non-SasView-derived) SANS sample models.
