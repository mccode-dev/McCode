Release: McXtrace 1.1

Blocks of attenuating material in off format

\subsection*{Description}
This component is a model of 1 or more off-shaped blocks attenuating the x-ray beam. Which shapes are present and their relative positions are described in a file of the follwing format: \#objects Material-filename OFF-filename x y z xwidth yheight zdepth ...

An example is; 2

\begin{verbatim}
Be.txt  cube.off  0 0.01 0    0 0 0
Rh.txt  chess.off 0 -0.01 0   0 0 0
\end{verbatim}

A xwidth etc of zero means use whatever dimensions are in the off/ply file. If xwidth (or yheight or zdepth) is nonzero, the component scales the object to fill that dimension. The xyz coordinates indicate the object shift.

Example: Abs\_objects(objects="input\_abs\_objects\_template.dat")
