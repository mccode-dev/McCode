\section{The \texttt{Shadow\_input} McXtrace Component}
Release: McXtrace 0.1

Read x-ray state parameters from SHADOW x-ray event file.

\subsection*{Identification}
\begin{itemize}
  \item \textbf{Author:} Andrea Prodi
  \item \textbf{Origin:} Risoe/ILL
  \item \textbf{Date:} November 21, 2011
\end{itemize}

\subsection*{Description}
Source-like component reading x-ray state parameters from a SHADOW x-ray event file. Used to interface McXtrace components or simulations into SHADOW.

Example: Shadow\_input(file="MySource.00", bufsize = 10000, repeat\_count = 2)

\subsection*{Input parameters}
Parameters in \textbf{boldface} are required; the others are optional.

\begin{longtable}{p{0.22\textwidth}p{0.12\textwidth}p{0.46\textwidth}p{0.14\textwidth}}
\toprule
\textbf{Name} & \textbf{Unit} & \textbf{Description} & \textbf{Default} \\
\midrule
\endhead
file & string & Filename of x-ray file to read. Default (NULL) is standard input. Empty string "" unactivates component & "" \\
bufsize & records & Size of x-ray input buffer & 10000 \\
repeat\_count & 1 & Number of times to repeat each x-ray read & 1 \\
\bottomrule
\end{longtable}
