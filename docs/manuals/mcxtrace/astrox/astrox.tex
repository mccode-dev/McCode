\chapter{AstroX components: X-ray optics for astronomical instrumentation}
\label{c:astrox}
\index{Library!Components!astrox}
\index{AstroX|textbf}

The \texttt{astrox} category collects components specific to the AstroX
branch of \MCX, modelling grazing-incidence X-ray optics of the kind used
in astronomical X-ray telescopes (nested Wolter-type mirror shells, pore
optics, and micropore/microchannel plate optics), together with a
dedicated extended source component suited to astronomical (rather than
laboratory or synchrotron) source geometries.

Each optical element is generally available in three variants, reflecting
the underlying mirror-shell geometry:
\begin{itemize}
\item \texttt{\_c}: conical approximation,
\item \texttt{\_p}: parabolic/hyperbolic (true Wolter-I) profile,
\item \texttt{\_h}: hyperbolic profile (second Wolter-I reflection).
\end{itemize}
