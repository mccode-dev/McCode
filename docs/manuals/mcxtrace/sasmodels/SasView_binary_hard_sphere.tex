\subsection*{Description}
SasView\_binary\_hard\_sphere component, generated from binary\_hard\_sphere.c in sasmodels.

Example: SasView\_binary\_hard\_sphere(radius\_lg, radius\_sm, volfraction\_lg, volfraction\_sm, sld\_lg, sld\_sm, sld\_solvent, model\_scale=1.0, model\_abs=0.0, xwidth=0.01, yheight=0.01, zdepth=0.005, R=0, int target\_index=1, target\_x=0, target\_y=0, target\_z=1, focus\_xw=0.5, focus\_yh=0.5, focus\_aw=0, focus\_ah=0, focus\_r=0, pd\_radius\_lg=0.0, pd\_radius\_sm=0.0)
