\subsection*{Description}
SasView\_lamellar\_stack\_paracrystal component, generated from lamellar\_stack\_paracrystal.c in sasmodels.

Example: SasView\_lamellar\_stack\_paracrystal(thickness, Nlayers, d\_spacing, sigma\_d, sld, sld\_solvent, model\_scale=1.0, model\_abs=0.0, xwidth=0.01, yheight=0.01, zdepth=0.005, R=0, int target\_index=1, target\_x=0, target\_y=0, target\_z=1, focus\_xw=0.5, focus\_yh=0.5, focus\_aw=0, focus\_ah=0, focus\_r=0, pd\_thickness=0.0)
