\section{The \texttt{Bragg\_crystal\_simple} McXtrace Component}
Perfect Bragg reflecting slab

\subsection*{Identification}
\begin{itemize}
  \item \textbf{Author:} Jose I. Robledo
  \item \textbf{Origin:} FaMAF - UNC, Argentina
  \item \textbf{Date:} February 2016
\end{itemize}

\subsection*{Description}
Rectangle of matter perfectly reflecting the incident X-ray beam that fulfills Bragg's law for a set of scattering vectors in the vicinity of the theoretical Q given a d-spacing. The rectangle is in the x-y plane.

Example: Bragg\_crystal\_simple( yheight=0.05, xwidth=0.02, DM=3.1356, err\_Q= 0.000075, r0=1.0)

\subsection*{Input parameters}
