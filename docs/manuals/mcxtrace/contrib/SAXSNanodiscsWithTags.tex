\section{The \texttt{SAXSNanodiscsWithTags} McXtrace Component}
A sample of monodisperse phospholipid bilayer nanodiscs in solution (water) - with
histidine tag still on the belt proteins.

\subsection*{Identification}
\begin{itemize}
  \item \textbf{Author:} Martin Cramer Pedersen (mcpe@nbi.dk)
  \item \textbf{Origin:} KU-Science
  \item \textbf{Date:} May 2, 2012
\end{itemize}

\subsection*{Description}
A component simulating the scattering from a box-shaped, thin solution (water) of monodisperse phospholipid bilayer nanodiscs - with histidine tags still on the belt proteins.

Example: SAXSNanodiscsWithTags( xwidth = 0.01, yheight = 0.01, zdepth = 0.01, SampleToDetectorDistance = 0.48, DetectorRadius = 0.1 )
