\chapter{Contributed components}
\label{c:contrib}
\index{Library!Components!contrib}
\index{Contrib|textbf}

The \texttt{contrib} category holds components contributed directly by
\MCX users, rather than authored and maintained by the core \MCX team.
The \MCX team provides the same technical support for these as for any
other component, but the original authors -- credited individually in each
component's source header and reproduced below -- carry primary
responsibility for the underlying physics and its validation. Always
check with \verb+mxdoc+ rather than an older document for a component's
current category.
