\chapter{Obsolete components}
\label{c:obsolete}
\index{Library!Components!obsolete}
\index{Obsolete|textbf}

Components in this chapter have been superseded, typically by a more
general or more robust replacement, and are kept solely so that existing
instrument files referencing them continue to compile and run. \textbf{Do
not use these in new instrument development.} Where a direct replacement
exists it is noted below; run \verb+mxdoc+ on the component name for the
authoritative, current pointer.

\begin{itemize}
\item \texttt{Perfect\_crystal} -- superseded by the \texttt{contrib} chapter's
  \texttt{Bragg\_crystal\_simple}/\texttt{Bragg\_crystal\_BC} family.
\item \texttt{Lens\_parab\_rough}, \texttt{Lens\_parab\_Cyl\_rough} -- early,
  roughness-aware refractive lens models, superseded by the current
  \texttt{Lens\_parab}/\texttt{Lens\_parab\_Cyl} components (see the Optics
  chapter).
\item \texttt{Lens\_Kinoform} -- an early kinoform refractive lens model.
\end{itemize}

This chapter is intentionally text-only: none of the components above ever had
a full manual entry of their own (\texttt{Perfect\_crystal}, \texttt{Lens\_Kinoform}
and the \texttt{\_rough} lens variants only ever carried short documentation
stubs), so there is nothing further to reproduce here beyond the summary
above. Run \verb+mxdoc+ on a component name for its full, current
documentation where one exists.
